# نظام إدارة المواعيد الطبية (Medical Appointment System)

نظام كامل لإدارة المرضى والحجوزات لمراكز وعيادات طبية — واجهة عصرية بـ HTML/CSS/Bootstrap 5 متصلة فعليًا بخلفية Google Sheets عبر Google Apps Script، **ثنائية اللغة (عربي/إنجليزي)** وقابلة للتثبيت كتطبيق على الجوال (PWA).

## حالة المشروع: مكتمل ✅
- واجهة كاملة (9 صفحات) متصلة ببيانات حقيقية عبر API.
- عمليات CRUD حقيقية على المرضى/مقدمي الخدمة/الخدمات.
- حجز مع **منع تضارب مواعيد فعلي على مستوى الخادم**.
- تصدير كل حجز عبر واتساب ويب / صورة PNG / PDF من أيقونة "مشاركة" واحدة.
- **إجراءات تفاعلية بلمسة واحدة** لتغيير حالة الحجز (تسجيل حضور / إنهاء / إلغاء) بدل القوائم المنسدلة.
- **دعم كامل للعربية والإنجليزية** مع تبديل فوري للاتجاه (RTL/LTR) وحفظ اللغة في حساب المستخدم.
- **PWA**: قابل للتثبيت على الشاشة الرئيسية بالجوال، بأيقونة خاصة وواجهة ملء شاشة.

> **قبل التشغيل:** اتبع `SETUP_GUIDE.md` لإنشاء قاعدة البيانات ونشر الـ API.

## الصفحات
| الملف | الوصف |
|---|---|
| `login.html` | تسجيل الدخول (متصل بورقة Users فعليًا، مع زر تبديل لغة) |
| `index.html` | الرئيسية — KPIs وآخر حجوزات اليوم من بيانات حقيقية |
| `patients.html` | إدارة المرضى — إضافة/تعديل/حذف/بحث فعلي |
| `providers.html` | مقدمو الخدمة — إضافة/تعديل/حذف + فلترة حسب النوع |
| `services.html` | الخدمات واحتياجاتها (طبيب/ممرضة/جهاز) |
| `booking.html` | الحجز — حقول ديناميكية حسب الخدمة + فحص تعارض حي مع الخادم |
| `daily-appointments.html` | الحجوزات اليومية — أزرار إجراء تفاعلية لكل حجز (حضور/إنهاء/إلغاء) |
| `reports.html` | تقارير اليوم/الشهر من بيانات حقيقية |
| `settings.html` | إعدادات المركز، نص رسالة واتساب، ولغة الحساب |

## الخلفية (Backend)
مجلد `apps-script/` يحتوي على كل كود Google Apps Script (9 ملفات .gs): التوجيه الرئيسي وإعداد الأوراق، تسجيل الدخول وحفظ لغة المستخدم، CRUD كامل للمرضى/مقدمي الخدمة/الخدمات، منطق منع تضارب المواعيد الفعلي، الإعدادات، والتقارير. راجع `SETUP_GUIDE.md` لتفاصيل كل ملف وخطوات النشر.

## طبقة الاتصال والدعم اللغوي (Frontend)
| الملف | المسؤولية |
|---|---|
| `js/config.js` | رابط الـ API |
| `js/api.js` | كل استدعاءات الـ API |
| `js/auth.js` | حماية الصفحات وتسجيل الخروج |
| `js/i18n.js` | **محرك الترجمة الكامل** (قاموس AR/EN، تبديل الاتجاه، حفظ لغة الحساب) |
| `js/export.js` | نافذة المشاركة (واتساب / PNG / PDF) |
| `js/app.js` | سلوك واجهة عام + تسجيل الـ Service Worker |
| `sw.js` | Service Worker بسيط لتفعيل خاصية التثبيت (PWA) |
| `manifest.json` | بيانات التطبيق وأيقوناته للتثبيت على الجوال |

## التقنيات
- HTML5, CSS3 (نظام تصميم عصري في `css/style.css` بخصائص CSS منطقية Logical Properties تدعم RTL/LTR تلقائيًا)
- Bootstrap 5 (يتبدّل بين نسخة RTL/LTR حسب اللغة المختارة)
- Font Awesome، SweetAlert2
- html2canvas + jsPDF (تصدير صورة/PDF)
- Google Sheets + Google Apps Script (Backend / API)
- PWA: Web App Manifest + Service Worker
- خطوط Google Fonts: Cairo / Tajawal / IBM Plex Mono

## فكرة التصميم (Signature)
كل نوع مقدم خدمة له **لون ثابت** في كل الشاشات: 🟢 تركواز = طبيب، 🟣 بنفسجي = ممرضة، 🟠 عنبري = جهاز.

## الإجراءات التفاعلية بدل القوائم
في شاشة الحجوزات اليومية، كل حجز له أزرار إجراء مباشرة بدل قائمة منسدلة:
- ✅ **تسجيل حضور** — لمسة واحدة.
- ✔️✔️ **إنهاء** — لمسة واحدة.
- ✖️ **إلغاء** — يطلب تأكيدًا سريعًا قبل التنفيذ (لأنه إجراء لا يمكن التراجع عنه بسهولة).
- ↩️ **إرجاع لمحجوز** — يظهر فقط للحجوزات الملغاة.

## أمان الـ API — مفتاح سري
كل طلب يوصل للـ API (سواء قراءة أو كتابة) لازم يبعت `apiKey` مطابقًا للقيمة المحفوظة في `apps-script/Code.gs`، وإلا يُرفض فورًا من السيرفر قبل تنفيذ أي شيء. المفتاح موجود في `js/config.js` (`Config.API_KEY`) ويُرسل تلقائيًا مع كل استدعاء عبر `js/api.js`. غيّر المفتاح الافتراضي المرفق بقيمة عشوائية خاصة بك في كلا الملفين (راجع الخطوة 6 في `SETUP_GUIDE.md`).

## منع تضارب المواعيد — كيف يعمل فعليًا
الفحص الحاسم يتم في `Api_Appointments.gs` على الخادم عند إنشاء الحجز، بمقارنة تقاطع الفترة الزمنية الجديدة مع كل حجوزات نفس مقدم الخدمة في نفس اليوم.

## الدعم ثنائي اللغة — كيف يعمل فعليًا
- `js/i18n.js` يحوي قاموسًا شاملًا لكل نصوص الواجهة، وأي عنصر عليه `data-i18n="key"` يُترجم تلقائيًا عند تحميل الصفحة.
- زر تبديل اللغة (أعلى كل صفحة + صفحة الإعدادات) يبدّل `dir`/`lang` على `<html>` وملف Bootstrap (RTL/LTR) فورًا.
- لو المستخدم مسجّل دخول، تبديل اللغة يُحفظ في عمود `Language` بورقة `Users` عبر `update_user_language` API — فتُطبَّق نفس اللغة تلقائيًا عند تسجيل الدخول من أي جهاز.
- بدون تسجيل دخول (أو بدون اتصال بالـ API)، اللغة تُحفظ محليًا في `localStorage` فقط.

## PWA — التثبيت على الجوال
`manifest.json` + `sw.js` + أيقونات `assets/icons/` تجعل الموقع قابلًا للتثبيت كتطبيق مستقل (Add to Home Screen) على أندرويد وiOS، بأيقونة مخصصة وواجهة ملء شاشة (بدون شريط المتصفح). راجع قسم PWA في `SETUP_GUIDE.md`.

## خطوات تالية اختيارية (لم تُنفَّذ، ليست ضرورية للتشغيل)
- شاشة إدارة مستخدمين داخل الواجهة (حاليًا تُدار يدويًا من ورقة Users).
- تجزئة (hash) كلمات المرور بدل التخزين النصي البسيط.
- إشعارات Push حقيقية (الـ Service Worker الحالي يخزّن الأصول فقط، بدون Push).
